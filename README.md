# RMP Android app

Android-приложение «Matule» — индивидуальное задание по дисциплине «Разработка мобильных приложений» (ИСПО СПбПУ).
Выполнено по конкурсному заданию компетенции «Разработка мобильных приложений» (модули А–Д).

## Стек

- Kotlin, Android Studio
- AGP 9.4.0, Gradle 9.6.1, Kotlin 2.2.10 (встроен в AGP)
- compileSdk 37, targetSdk 36, minSdk 26
- Библиотеки: AndroidX, Material, Kotlin Coroutines, Gson; в сетевом слое — Retrofit и OkHttp

## Структура проекта

| Модуль | Назначение |
| --- | --- |
| `uikit` | Библиотека компонентов: цвета, типографика, шрифт иконок, Input, Select, BottomSheet, Search, кнопки, TabBar, карточка, Header |
| `network` | Библиотека сетевого слоя: модели сервера, сетевой клиент, запросы, обработка ошибок |
| `app` | Приложение |

Приложение разделено на слои:

```
app/src/main/java/ru/samoylov/matule/
├── domain/        модели, интерфейсы репозиториев, use case
├── data/          реализация репозиториев, мапперы, локальное хранилище
├── presentation/  экраны (Activity / Fragment) и ViewModel
├── common/        общие классы (уведомления)
└── di/            ServiceLocator — ручное внедрение зависимостей
```

Экраны обращаются к сети только через интерфейсы репозиториев, поэтому библиотеку `network` можно заменить, не трогая экраны.

## Что реализовано

**Экраны:** заставка, вход и регистрация, создание профиля, создание пароля, PIN-код / биометрия, главная, каталог с поиском, корзина, список проектов, создание проекта, профиль. Витрина UIKit открывается долгим нажатием на надпись на заставке.

**Хранение информации:**
- сохранение сессии и данных входа после перезапуска;
- кэширование главной страницы (акции и товары);
- восстановление последнего открытого экрана после перезапуска;
- сохранение заполненных полей на экранах «Создание профиля» и «Создание проекта»;
- политика конфиденциальности (PDF) и пользовательское соглашение в профиле.

**Аппаратные возможности:**
- выбор фото проекта из галереи или съёмка камерой;
- локальное уведомление, если в последнем открытом проекте нет действий 1 минуту;
- локальное уведомление, если приложение не открывали больше минуты (один раз до следующего входа).

## Запуск

1. Android Studio → File → Open → корневая папка проекта.
2. Дождаться Gradle Sync.
3. Run 'app'.

По умолчанию приложение работает на тестовых данных (`FakeApiService`). Переключение на настоящий сервер — константа `USE_FAKE_API` в `app/.../di/ServiceLocator.kt`, адрес сервера — в `network/.../ApiConfig.kt`.

## Ограничения

- Фото проекта хранится на устройстве и на сервер не отправляется.
- Запланированные напоминания сбрасываются после перезагрузки телефона.
